## 免费版够用吗，有哪些不花钱的办法

免费版能显示按键状态，但授权只限个人使用，触发器、通知和图标主题这些 Pro 功能都没有。

触发器是 Pro 里最有存在感的一个功能，可以设定某个程序获得焦点时自动关掉 Caps Lock。经常在游戏和聊天窗口之间切、又老被大写坑到的人，光这一个功能就值回 14 美元。其余几项属于“有了更好”的范畴，日常感知没那么强。

不想花钱，Windows 自带的功能和键盘厂商的驱动能顶一部分用。

- 切换键提示音。按住 Num Lock 五秒，系统会问你要不要开启“切换键”，开启之后每次按 Caps Lock 都会响一声，听声音就知道状态，零成本。
- 屏幕键盘。运行 osk.exe，Caps Lock 开没开，键位上直接看得见。
- 键盘厂商的驱动。罗技、雷蛇这类游戏键盘的配套软件，按锁定键时会在屏幕上弹提示。
- 笔记本自带的 OSD。不少商务本切换 Caps Lock 时，屏幕角落会闪一下图标，只是很多人没注意。

这些办法的共同问题是，只能在“按下去那一瞬间”告诉你状态，给不了托盘里那个常驻的小图标。TrayStatus 卖的就是这份常驻的安心感，值不值 14 美元，取决于你被大写坑的频率。

## 几个买之前该知道的限制

**只支持 Windows。** 系统要求是 Windows 11、Windows 10（1607 及以上）、Windows Server 2022/2019/2016，32 位和 64 位都支持。没有 macOS 版，也没有 Linux 版。

**依赖 .NET 和 WebView2。** 安装时会自动装 .NET 7 桌面运行时和 WebView2 运行时，家用电脑一般不构成问题，公司锁了安装权限的机器可能过不去这一步。

**Standard 只授权 1 台电脑。** 换电脑、重装系统之后授权怎么迁移，买之前最好问清楚。两台以上就别省那 5 美元了。

**功能确实单一。** 它不监控电池、不显示天气、不管剪贴板，就是个键盘状态灯。拿它跟 PowerToys 那种工具箱比会觉得亏，但两者解决的问题不一样。

**中文资料少。** 这软件在国内讨论不多，搜到的多是英文下载站的介绍，遇到问题得看英文文档。

**买断制反而是优点。** 一次付费，没有第二年涨价这回事，这点比很多同类工具让人放心。
